# Contributing
Thank you for your interest in contributing to Writit! Anyone is allowed provide any sort of contributions, such as issues and pull requests.

## How to start?
If you are looking for an issue to resolve, look for issues with the `good first issue` tag. This indicates a beginner-friendly/easy to solve issue.
Once you have found an issue you wish to work on, ask to be assigned to the issue from a contributor.

**Alternatively**, if you are looking to contribute code via a pull request, keep these things in mind:
- Keep it simple: ensure your PR does not contain many complex technical terms, as it may make the issue harder to understand
- Open only meaningful PRs: don't open a pull request just to contribute nothing meaningful to Writit.
