# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| > 1.0.0   | :white_check_mark: |
| 0.x.x-beta   | :x:              |

Beta versions of Writit are no longer supported. Only the latest release will be supported, past releases will not be modified.

## Reporting a Vulnerability
When you discover a vulnerability, **DO NOT** open an issue or pull request about it. Instead, you should report it. 
To report a vulnerability, use GitHub's Private Vulnerability Disclosure functionality. For more information, see https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability#privately-reporting-a-security-vulnerability
